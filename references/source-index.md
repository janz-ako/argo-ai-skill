## Source limitations

- ARGO's repository was archived in November 2022 and is read-only.
- The repository says the software is no longer under active development.
- Wiki content dates mainly from 2017–2021.
- Some wiki entries contain typographical or descriptive ambiguities, especially certain expected gain/loss functions.
- `RtaTriangularAlt` is listed but not described in detail on the distribution page.
- The skill therefore marks uncertain details for verification using Excel's installed Function Wizard or IntelliSense.

## Methodological content

Distribution-selection, construction-risk, project-finance, validation, and reconciliation guidance in this package is professional modelling guidance layered on top of verified ARGO syntax. It is not presented as quoted ARGO documentation.
