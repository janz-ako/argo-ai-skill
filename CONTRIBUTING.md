# Contributing
Thank you for your interest in improving the ARGO AI Skill!
Contributions
- Bug fixes
- Documentation improvements
- Additional ARGO examples
- Monte Carlo modelling best practices
- Construction, finance, and risk analysis examples
- Improvements to the Python validator
- New tests and validation cases

## Before contributing
Please:
- Search existing issues before opening a new one.
- Open an issue first for significant changes so we can discuss the approach.
- Keep pull requests focused on a single topic whenever possible.

## Documentation
When contributing documentation:
- Prefer references to the official ARGO documentation where available.
- Clearly distinguish verified ARGO behaviour from modelling recommendations.
- Include practical examples whenever possible.

## Code
If contributing code:
- Keep it simple and well documented.
- Ensure existing functionality continues to work.
- Add or update tests when appropriate.

## Reporting Issues
When reporting a bug, please include:
- ARGO version (if known)
- Excel version
- Operating system
- The formula or workbook involved
- The expected behaviour
- The actual behaviour

## Code of Conduct
Please be respectful and constructive. The goal of this project is to build a high-quality community resource for ARGO users.
